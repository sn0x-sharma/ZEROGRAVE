Firefox PQuota missing TrustParams gate PoC — sn0x

Execution context: a compromised content process. Not reachable from web content, so this page is a results viewer for poc.py / poc-getusage.py rather than a trigger.
RUNTIME-CONFIRMED Reproduced on stock Firefox 153.0.1, default profile, no prefs changed.

Defect

QuotaParent.cpp gates its 34 IPC handlers individually, using four different idioms. 12 handlers have no gate at all — and the distribution is inverted: every scoped clear/shutdown variant is gated, while both global ones are not.

operationscopegated
ClearStoragesForOrigin / ForClient / ForOriginPrefix / ForOriginAttributesPattern / ForPrivateBrowsingscopedall five
ClearStorageevery originno
ShutdownStoragesForOrigin / ForClientscopedboth
ShutdownStorageglobalno

ListOrigins, ListCachedOrigins and GetUsage are worse still: they carry neither the child-side dom.quotaManager.testing pref nor a parent gate. Nothing to bypass.
